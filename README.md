# testrepository

Minimales TypeScript-„Hello World“, das per GitHub Actions gebaut und als GitHub Page veröffentlicht wird.

- Lokal bauen: `npm ci && npm run build` → Ergebnis in `dist/`
- Deployment: `.github/workflows/deploy.yml`
- Einmalig nötig: **Settings → Pages → Build and deployment → Source: „GitHub Actions“**
